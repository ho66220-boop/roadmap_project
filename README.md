# 울산 고1 과목 선택 상담 웹앱

울산 지역 고등학교 1학년(2026년 입학)이 "목표 학과 + 우리 학교"를 입력하면, 필요한 과목을 **3단계로 대조**해 알려주는 상담 도구입니다.

1. **학과 추천 과목** (커리어넷) — 목표 학과의 일반/진로/융합 선택과목
2. **대학별 강조 과목** (대교협 시행계획) — 관련 모집단위들이 핵심/권장으로 제시한 과목과 제시율(%)
3. **우리 학교 편제표 대조** — 위 추천 과목이 실제로 개설되는지, **몇 학년 몇 학기**인지, **학교지정인지 택N 선택군**(직접 신청 필요)인지, 어느 학교에도 없는 과목(공동교육과정·온라인학교 확인 대상)인지

모든 계산은 **순수 결정론적 로직**입니다. 런타임에 LLM이나 외부 API를 호출하지 않으며, 같은 입력은 항상 같은 결과를 냅니다.

## 아키텍처

```
[원자료]                          [전처리]                    [산출물/배포]
울산 고교 편제표 40개교 xlsx ──▶ build_curriculum.py ──▶ curriculum_g1_2026.xlsx
                                (파서 v2: 병합셀 복원,        (20열: 개설학기 + 선택군ID·택N
                                 택N 그룹, 정제로그)            + 검증요약/정제로그 시트)
울산고교_과목로드맵_수정.xlsx ─────────────┐                        │
(학과추천·대학트랙·제시율·과목마스터)      │                        ▼
                                          └──▶ export_for_gsheet.py ──▶ gsheet_upload.xlsx
                                                                            │
                        ┌───────────────────────────────────────────────────┤
                        ▼                                                   ▼
              로컬 개발용: server.py + app/            실서비스: 구글 시트 + Apps Script 웹앱
              (표준 라이브러리 HTTP 서버)               (apps_script/ — 학원 PC에서 파이썬 실행이
                                                        차단되어 있어 GAS로 배포)
```

추천 엔진은 두 벌이 **항상 동일 로직으로 유지**됩니다: [roadmap_rag/graph_rag.py](roadmap_rag/graph_rag.py)(Python, 개발·검증용)와 [apps_script/Code.gs](apps_script/Code.gs)(실배포용). 로직을 수정하면 양쪽에 반영하고 Node 모킹 하니스로 필드 단위 패리티를 검증합니다.

## 실행 방법

### 요구 사항

- Python 3.10+ / 의존성은 `openpyxl` 하나 (`pip install -r requirements.txt`)
- **원본 데이터 필요**: `울산고교_과목로드맵_수정.xlsx`와 `울산 고교 편제표/` 폴더(40개교 신입생 3개년 편제표)가 저장소 상위 폴더에 있어야 합니다. 이 데이터는 저작권·개인정보 검토 문제로 **저장소에 포함되지 않으므로, 클론만으로는 실행할 수 없습니다.** (`data/sample_*.xlsx`는 구버전 엔진용 샘플로 현행 파이프라인과 호환되지 않습니다)

### 파이프라인

```powershell
python scripts\build_curriculum.py     # 편제표 40개교 파싱 → data/curriculum_g1_2026.xlsx
python scripts\export_for_gsheet.py    # 구글 시트 업로드용 통합 파일 생성 (기본: 전 학교 노출)
python server.py                       # 로컬 상담 UI → http://localhost:8000
python -m unittest discover -s tests   # 테스트 48개
```

편제표가 바뀌지 않았다면 `server.py`만 실행하면 됩니다. 파서 산출물에는 검증요약·정제로그·택N그룹 시트가 함께 들어 있어 파싱 품질을 감사할 수 있습니다.

### 실서비스 배포 (Google Apps Script)

학원 PC에서는 파이썬 실행이 차단되어 있어 실서비스는 구글 시트 기반 웹앱으로 배포합니다. `gsheet_upload.xlsx`를 구글 시트로 변환하고 `apps_script/`의 두 파일을 붙여넣어 웹 앱으로 배포합니다 — 절차는 [apps_script/README.md](apps_script/README.md) 참고.

### API (로컬 서버)

- `GET /api/meta` — 로드된 학교·학과 목록
- `POST /api/chat` — `{"profile": {"school": "신정고", "grade": 1, "major": "컴퓨터공학과"}}` → 3단계 리포트(JSON)

## 한계와 윤리

- 본 서비스는 입시 결과를 보장하지 않습니다. 편제표와 대학별 계획은 변경될 수 있으므로 결과 화면에 항상 데이터 기준일과 최종 확인 안내를 표시합니다.
- 택N 선택군은 "이 과목이 이 선택군에 개설된다"까지만 안내하며, 선택 개수 규칙 강제나 시간표 충돌 검사는 하지 않습니다.
- 특수 목적 과목(연극·전문교과 등)과 자체개발 과목은 추천 대조 대상에서 제외되거나 "공통 미개설"로 표시됩니다.
- 데이터를 수집·가공하는 과정에서만 AI 도구를 활용했고, 산출된 코드와 런타임에는 어떤 LLM 추론도 포함되지 않습니다.
