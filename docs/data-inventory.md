| 필드 | 설명 |
| --- | --- |

| cohort_year | 입학생 기준 연도 |
| grade | 학년 |
| semester | 학기 |
| slot_id | 선택 묶음 식별자 |
| subject_name_raw | 원본 과목명 |
| subject_name_normalized | 정규화 과목명 |
| subject_code | 공식 과목 코드 |
| credit | 학점/단위 |
| choice_rule | 택N, 필수, 교차 선택 등 |
