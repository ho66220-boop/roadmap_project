# Graph RAG 아키텍처

## 목표

학생의 학교·학년·수강 과목·목표 학과·내신 정보를 구조화하고, 학교 편제표와 대학 시행계획 근거를 함께 검색해 설명 가능한 진로 상담 답변을 생성합니다.

## 구성 요소

```text
Raw Data
  -> Extract/Normalize
  -> Graph Store + Vector Index
  -> Retrieval Planner
  -> Recommendation Engine
  -> LLM Counseling Layer
  -> Web Chat UI
```

## 그래프 노드

| 노드 | 예시 속성 |
| --- | --- |
| School | 학교명, 지역, 유형 |
| CurriculumSlot | 학교, 학년, 학기, 선택 규칙, 최소/최대 선택 수 |
| Subject | 공식 과목명, 과목 코드, 교과군, 과목유형, 별칭 |
| University | 대학명, 지역 |
| Major | 모집단위명, 표준 학과명, 계열 |
| AdmissionPlan | 전형명, 연도, 모집인원, 반영 방식 |
| StudentProfile | 학년, 내신, 이수 과목, 목표 학과 |

## 그래프 관계

| 관계 | 의미 |
| --- | --- |
| `OFFERS` | 학교가 선택 슬롯을 제공 |
| `CONTAINS` | 선택 슬롯에 과목이 포함 |
| `REQUIRES_CORE` | 학과/대학이 핵심 과목으로 요구 |
| `RECOMMENDS` | 학과/대학이 권장 과목으로 제시 |
| `HAS_PLAN` | 대학/학과가 시행계획을 가짐 |
| `SIMILAR_TO` | 학과 간 유사 관계 |
| `TAKEN` | 학생이 과목을 이수 |
| `TARGETS` | 학생이 목표 학과를 희망 |

## 검색 흐름

### 고1·고2 로드맵

1. 학생 입력을 구조화합니다.
2. 목표 학과를 표준 학과명으로 정규화합니다.
3. 목표 학과의 핵심/권장 과목을 가져옵니다.
4. 학생 학교의 남은 학기 선택 슬롯에서 개설 가능한 과목만 필터링합니다.
5. 이미 이수한 과목과 비교해 부족한 과목을 찾습니다.
6. 학기별 추천 로드맵과 대체 과목을 생성합니다.

### 고3 대학/학과 탐색

1. 학교, 내신, 이수 과목, 목표 학과를 입력받습니다.
2. 목표 학과와 유사 학과 후보를 확장합니다.
3. 대학별 학과 후보를 과목 적합도와 내신컷으로 필터링합니다.
4. 상향/적정/안정 후보를 분리합니다.
5. 과목 선택 근거와 데이터 한계를 함께 설명합니다.

## LLM 역할

LLM은 추천 점수를 임의로 만들지 않습니다. 계산과 필터링은 그래프/추천 엔진이 담당하고, LLM은 다음 역할만 수행합니다.

- 학생 질문 의도 파악
- 누락된 입력값 확인 질문 생성
- 검색 결과를 상담 문장으로 재구성
- 근거 자료 요약
- 불확실성과 최종 확인 필요 사항 안내

## 평가 지표

- 과목명 정규화 정확도
- 학교별 실제 개설 과목 매칭률
- 목표 학과 핵심 과목 충족도 계산 정확도
- 추천 결과의 근거 표시율
- 상담 답변에서 허위 전형 정보가 생성되지 않는 비율
