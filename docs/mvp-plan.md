# MVP 구현 계획

## 1단계: 데이터 검증

- 엑셀 시트별 행/열, 헤더, 결측치 확인
- 과목명 별칭과 공식 과목 코드 매핑률 계산
- 학교별 편제표 파일명에서 학교명과 편제 유형 추출
- 대학 시행계획 파일 목록과 확장자 분포 정리

산출물:

- `data/source_manifest.json`
- `data/schema.md`
- 변환 실패 케이스 목록

## 2단계: 고1·고2 과목 로드맵 MVP

입력:

- 학교명
- 현재 학년
- 이미 수강한 과목
- 목표 학과 또는 계열

출력:

- 남은 학기별 추천 과목
- 핵심 과목 충족/부족 현황
- 학교 편제표에 없는 과목과 대체 과목
- 추천 근거가 된 대학/학과 데이터

현재 구현 상태:

- `server.py`에서 엑셀 기반 Graph RAG 챗봇 API 제공
- 학교 편제표와 학과별 추천 과목을 연결해 추천/확인 필요 과목 분류
- `app/index.html`에서 채팅, 추천 과목, 학기별 로드맵, 근거 그래프 표시

## 3단계: Graph RAG 챗봇

필수 질의 예시:

- "울산고 1학년이고 컴퓨터공학과 희망인데 2학년 때 어떤 과목을 골라야 해?"
- "생명과학과 목표인데 우리 학교 편제표에서 화학Ⅱ를 못 들으면 어떻게 해야 해?"
- "기계공학과는 물리학이 꼭 필요한가?"

응답 원칙:

- 학교 편제표에 실제로 있는 과목만 추천
- 핵심/권장/참고 과목을 구분
- 자료 기준 연도와 한계를 명시
- 모르는 내신컷이나 전형 결과를 추정하지 않음

현재 MVP는 외부 LLM 호출 없이 규칙 기반 상담 문장을 생성합니다. 다음 단계에서 LLM을 붙일 때도 추천 계산은 현재 엔진이 담당하고, LLM은 말투와 설명 재구성에만 사용합니다.

## 4단계: 고3 내신 기반 추천

추가 데이터:

- 최근 3개년 대학/학과별 내신컷
- 전형별 모집단위 변화
- 지역/전형/교과 반영 방식

출력:

- 지원 가능 후보
- 유사 학과 상향 후보
- 안정 후보
- 과목 적합도 보완 조언

## 우선순위

1. 고1·고2 로드맵부터 구현
2. 내신컷 없는 고3 기능은 "과목 적합도 기반 탐색"으로 제한
3. 내신컷 확보 후 지원권 추천 확장
