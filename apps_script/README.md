# 구글 시트 웹앱 배포 가이드

학원 등 파이썬 실행이 차단된 환경에서 쓰는 Google Sheets + Apps Script 버전입니다.
로컬 파이썬 버전(`server.py`)과 동일한 3단계 추천 로직(커리어넷 → 대교협 → 학교 편제표)을 제공합니다.

## 구성 파일

| 파일 | 역할 |
| --- | --- |
| `Code.gs` | 추천 엔진 + 웹앱 서버 (스프레드시트에서 데이터 로딩) |
| `index.html` | 상담 UI (Apps Script HtmlService로 서빙) |

## 1. 데이터 준비 (로컬에서 1회)

```powershell
python scripts\build_curriculum.py     # 편제표가 바뀐 경우에만
python scripts\export_for_gsheet.py    # data/gsheet_upload.xlsx 생성
```

`data/gsheet_upload.xlsx`에는 웹앱에 필요한 6개 시트가 모두 들어 있습니다:
`고1편제표`, `학과추천`, `대학트랙`, `대학제시율_학과`, `대학제시율_계열`, `과목마스터`

## 2. 구글 시트 만들기

1. `gsheet_upload.xlsx`를 구글 드라이브에 업로드
2. 파일을 열고 **파일 > Google Sheets로 저장** (또는 업로드 시 자동 변환 설정)
3. 변환된 스프레드시트의 시트 이름 6개가 위와 정확히 같은지 확인 (엔진이 시트 이름으로 찾음)

## 3. Apps Script 붙여넣기

1. 스프레드시트에서 **확장 프로그램 > Apps Script** 열기
2. 기본 `Code.gs`의 내용을 지우고 이 폴더의 `Code.gs` 내용으로 교체
3. **파일 추가(+) > HTML**, 이름을 `index`로 하고 이 폴더의 `index.html` 내용 붙여넣기
   (이름이 `index`가 아니면 `doGet`의 `createHtmlOutputFromFile('index')`와 어긋나 오류)
4. 저장

## 4. 웹앱 배포

1. 우측 상단 **배포 > 새 배포**
2. 유형: **웹 앱**
3. 설정
   - 실행 계정: **나** (데이터 시트 접근 권한이 배포자 기준)
   - 액세스 권한: **링크가 있는 모든 사용자** (학원생 공유용) 또는 원하는 범위
4. 배포 후 처음 한 번 권한 승인
5. 발급된 웹앱 URL을 학생/강사에게 공유

## 5. 데이터 갱신

편제표나 추천 데이터가 바뀌면:

1. 로컬에서 1번 절차 재실행 → 새 `gsheet_upload.xlsx`
2. 스프레드시트의 각 시트 내용을 새 파일 내용으로 교체
   (시트 이름만 유지되면 코드는 수정할 필요 없음)
3. 코드가 바뀐 경우에만 **배포 > 배포 관리 > 수정 > 새 버전**으로 재배포

## 동작 특성·주의

- 요청마다 시트 전체(약 2.3만 행)를 읽으므로 응답에 **2~5초** 걸립니다. UI에 로딩 표시가 있습니다.
- Apps Script 무료 할당량(일일 실행 시간 등)은 학원 규모 사용에는 충분합니다.
- **노출 범위**: 기본으로 파싱된 전 학교(40개교, 울산외고는 영어과/비영어과 분리)를 노출해 로컬 파이썬 서버와 동일합니다. 재원생 학교(10개교)만 노출하려면 `python scripts\export_for_gsheet.py --target-only`로 생성한 파일을 쓰세요.
- 파싱된 적 없는 새 학교를 추가하는 경우엔 `data/curriculum_sheetmap.csv`에 시트맵을 추가하고 `build_curriculum.py` → `export_for_gsheet.py`를 재실행해야 합니다.
- 시트를 직접 수정해도 됩니다(예: 미개설 과목 보정). 단 열 순서는 유지하세요.
